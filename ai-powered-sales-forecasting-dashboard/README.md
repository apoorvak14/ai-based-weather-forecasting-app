# AI-Powered Sales Forecasting and Business Insights Dashboard

A complete offline dashboard for sales forecasting, KPI tracking, and business insight generation. It runs in any modern browser and does not require a backend or paid API key.

## Features

- Interactive sales KPI dashboard
- Revenue, orders, profit, margin, average order value, and growth metrics
- Region and product category filtering
- 6-month sales forecast using trend, seasonal index, and confidence bands
- Business insight cards generated from the selected data
- CSV upload support
- Built-in sample dataset
- Responsive layout for desktop and mobile

## How To Run

Open `index.html` directly in a browser.

Optional local server:

```bash
npm start
```

Optional smoke test:

```bash
npm test
```

## CSV Format

Upload a CSV with these columns:

```csv
date,region,category,revenue,orders,profit
2025-01-01,North,Software,12500,86,4200
```

Dates should be parseable by JavaScript, and numeric columns should contain plain numbers.

## Forecasting Method

The dashboard uses a lightweight local model:

- Monthly aggregation of selected records
- Linear trend estimate from monthly revenue
- Seasonal index based on month-of-year historical averages
- Confidence range estimated from recent residual error

The insight cards are generated by deterministic analysis rules so the project is fully usable offline.
